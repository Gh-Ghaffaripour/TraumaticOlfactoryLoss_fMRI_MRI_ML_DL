# TraumaticOlfactoryLoss_fMRI_MRI_ML_DL
This repository contains the codebase for our research on diagnosing traumatic olfactory loss using machine learning and deep learning. We leverage functional (fMRI) and structural (MRI) neuroimaging data to develop and evaluate supervised classification models.
